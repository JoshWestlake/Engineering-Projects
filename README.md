## Conventions
- Lowercase folder names with hyphens.
- Use `templates/PROJECT_README.md` for new projects; only create the subfolders a project uses.
- Large CAD files go through Git LFS (see `.gitattributes`); always include STEP exports in `cad/step/`.
- Files must stay under GitHub's 100 MB limit.
